AI-powered document analysis and audit questionnaire generation using Pydantic AI, AG-UI protocol, and CopilotKit v2.

    │   ├── components/

## Layout

Three-pane layout (left to right):

1. **Chat UI** — CopilotKit sidebar with file upload (.pdf, .docx, .xlsx)
2. **Documents** — List of uploaded/retrieved document cards with selection
3. **Generative UI Output** — Forms, charts, tables generated by the agent

## Component Catalog (Simplified)

| Component | Purpose |
|-----------|---------|
| `DocumentCard` | Document display with metadata and checkbox |
| `AuditQuestionForm` | Audit questions with expandable sub-questions |
| `TextBox` | General-purpose text/insight display (info/warning/success/error) |
| `DataTable` | Structured tabular data with optional sorting |
| `SimpleChart` | Simple bar, line, or pie charts (pure SVG) |

## Quick Start

### Backend

```bash
cd agui_v2/agent
python -m venv .venv && source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
echo "OPENAI_API_KEY=sk-..." > .env
python main.py
# Runs on http://localhost:8001
```

### Frontend

```bash
cd agui_v2/frontend
npm install
npm run dev
# Runs on http://localhost:3011
```

## AG-UI Protocol

The backend serves AG-UI over SSE at `POST /`. Events are transformed from
PascalCase to SCREAMING_SNAKE_CASE for CopilotKit v2 compatibility. The
frontend connects via `@ag-ui/client`'s `HttpAgent` and uses CopilotKit v2's
`useAgent` hook for bidirectional state sync.

## Agent Tools

| Tool | Description |
|------|-------------|
| `get_documents` | Retrieve list of uploaded documents from state |
| `analyze_documents` | Process documents and extract audit-relevant info |
| `generate_audit_form` | Generate questionnaire + insight components |
